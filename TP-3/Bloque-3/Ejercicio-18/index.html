Propiedades CSS Utilizadas

  • grid-template-columns: repeat(auto-fill, minmax(200px, 1fr)) - Crea columnas que se adaptan
  • grid-auto-flow: dense - Rellena huecos automáticamente
  • grid-column: span 2 - Item ocupa 2 columnas
  • grid-row: span 2 - Item ocupa 2 filas
  • Los items grandes se distribuyen sin crear espacios vacíos
