# Diseño UX-UI 2026 - FCyT

---

## 📋 Descripción general

Repositorio de entregas de la materia **Diseño UX-UI 2026**, correspondiente a la FCyT.

En este repositorio se encuentran los trabajos prácticos realizados durante la cursada, aplicando conceptos de diseño UX/UI y desarrollo de interfaces digitales.

## 📚 Trabajos prácticos

### TP3 - HTML y CSS

Desarrollo de una interfaz web utilizando **HTML y CSS**, aplicando conceptos de estructura, estilos y diseño visual.

### TP5 - Contratación digital de seguros

Diseño de una experiencia digital para el proceso de **contratación de seguros**, teniendo en cuenta la experiencia del usuario (UX), la interfaz visual (UI) y la facilidad de uso del proceso.
